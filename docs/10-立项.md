## 1. 项目背景

**定位**：allin-one 是 the-one（数字大脑）的感知与记录层——一个部署在家庭服务器、可独立离线运行的个人内容与数据服务。它存"记录"（读过什么、看过什么、记了什么、有什么），the-one 存"判断"（画像、研判、预测、复盘）。

## 2. 应用场景

**实际使用行为**（2026-09 观察）：

- 手机：刷信息流、看影视库、标记看过/想看。
- 桌面终端（the-one 会话）：`/digest` 拉信息流做研判，`/mentor`、`/trader` 按关键词取内容，影视库经 MCP 做推荐与批量标记，金融数据经 MCP 取行情与宏观。
- Emby 看片后 30 分钟内自动同步观看事实到影视库。
- 电子书标注、备忘、日记目前没有使用（无入口或数据为空）。

**数字痕迹覆盖**：

| 类别 | 痕迹 | 今日覆盖 |
|---|---|---|
| 摄入 | 文章、播客 | 信息流：57 个 RSS 源、6 个播客源，11,484 条 |
| 摄入 | 影视 | 影视库：1,177 部，Emby 同步 + 手工 |
| 摄入 | 书与标注 | 图书馆：功能在，数据为空（迁移未恢复） |
| 摄入 | B 站视频 | 同步源存在，未授权，停用 |
| 摄入 | 音乐 | 无 |
| 产出 | 备忘、日记、AI 会话 | 无入口。`user_note` 字段存在但无数据 |
| 交流 | 消息、邮件、日历 | 无 |
| 财务 | 行情与宏观 | `finance_data_points`（AkShare/蚂蚁）；个人流水无 |
| 身体 / 时空 / 环境 | 体检、位置、家居 | 无 |
| 影像 | 照片 | 无 |
| 判断 | 画像、研判 | 不在本系统，在 the-one |

**the-one 侧的消费方式**：`scripts/intel-query.py`（REST，`X-API-Key`）按「情报」过滤器圈定的源拉内容，以水位线做增量；MCP server（192.168.1.103:8001）提供 20 个工具，见 50-用例。

## 3. 概念辨析

系统内正在使用的概念，含义以代码与文档为准：

| 概念 | 含义 |
|---|---|
| **信息流 / 资料库** | 两条主线。信息流：采集来的时效内容（RSS、播客、抓取），进流水线，按保留期清理。资料库：影视、电子书、书签、笔记、上传文件、同步来的视频，不进流水线，永不自动清理。 |
| **kind** | `content_items.kind`，内容的领域身份，写入时确定。现值：article、audio、video、book、film、bookmark、note、file。 |
| **数据源 / 订阅源** | 数据源（`source_configs`）是"从哪来"的配置，统一术语；订阅源专指 RSS feed。 |
| **源类型** | `source_types.py` 注册表的一条：执行器（collector / syncer / push / none）、默认 kind、可否调度、是否需凭证、领域、自动同步间隔、是否已实现。 |
| **采集 / 同步 / 推送** | 采集：Collector 增量追加，可调度。同步：内置 Syncer 全量对账（Emby、微信读书、B 站）。推送：外部脚本或 Fountain 客户端 POST 到 `/api/{ebook,video,bookmark}/sync`。 |
| **流水线** | 由模板显式定义的步骤序列（抽取、抓全文、翻译、媒体本地化、转写、LLM 分析、推送），经 `source.pipeline_template_id` 绑定；无模板则内容直接 ready。 |
| **收藏 / 已打开 / 已读** | 收藏：`is_favorited`，保留策略豁免，触发媒体本地化。已打开：`opened_at`，仅详情接口写。已读：`view_count` / `last_viewed_at`，含滚动与批量标记，与 app 端共享，不作研判依据。 |
| **情报过滤器** | `system_settings.content.filters` 里名为「情报」的过滤器，圈定 the-one 研判用的源；过滤器之间允许重叠。 |
| **记录 / 判断** | 分界规则：会被反复改写的（画像、话题、研判手册、预测、复盘）归 the-one；只追加不重写的（一条内容、一次观看、一条标注）归 allin-one。the-one 引用本系统对象写 `content:<id>`，不复制正文。 |
| **自有副本** | 落地到本系统的资源（海报、插图、封面）都是自有副本，不视为可从上游重拉的缓存，都在备份范围内。 |
| **反射 / 认知** | 反射：单条内容、不依赖 doctrine 的处理（抽取、摘要、标签、去重），在本系统流水线。认知：跨条目、依赖研判手册与记忆的判断，在 the-one skill。 |
