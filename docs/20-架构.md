## 1. 领域划分

**两条主线**：

| | 信息流 | 资料库 |
|---|---|---|
| kind | article、audio | film、book、bookmark、note、file、video |
| 进入 | 采集（Collector，调度器每分钟检查到期源） | 同步（Emby 每 30 分钟自动；微信读书、B 站手动）、推送（外部脚本）、手工添加 |
| 处理 | 流水线（模板绑定） | 无，直接 ready；元数据补全各领域自理（影视 TMDb、图书 Google Books） |
| 清理 | `content_retention.py`：按保留期删，收藏 / 有笔记 / 有收藏媒体的受保护 | 永不自动清理；有内容的用户数据源拒绝非级联删除 |
| 信息流口径 | 通用列表、未读数、仪表盘、日报、MCP `list_content` | 排除 `FEED_HIDDEN_KINDS`（目前 film） |

**领域现状**：

| 领域 | kind | 来源（源类型） | 页面 | 用户状态 | 数据（2026-09-23） |

## 2. 技术选型

| 层 | 技术 | 用途 / 边界 |
|---|---|---|
| 后端 | Python 3.11、FastAPI、SQLAlchemy、Alembic | REST `/api`，鉴权 `X-API-Key`；迁移当前 head `0028` |
| 数据库 | PostgreSQL 17（容器 `allin-postgres`，volume `allin-one_postgres_data`） | 唯一结构化存储，101MB；容器 `TZ=UTC`（home-server compose 里只有它设了 TZ），应用层统一 `app.core.time.utcnow` naive UTC |
| 任务队列 | Procrastinate（Postgres 表做队列） | 两个 worker：`pipeline` 队列并发 4、`scheduled` 队列并发 2；periodic 任务见 40-流程 |
| 前端 | Vue 3 `<script setup>`、Vite、TailwindCSS | 单页应用，构建产物打进后端镜像 |
| MCP | `backend/mcp_server.py`，HTTP 端点绑定 192.168.1.103:8001 | 20 个工具；无应用层认证，不配置公网反代（运维手册） |
| 采集 | feedparser（RSS 直连）、RSSHub（19 个数据源的 URL 指向 `rsshub:1200`，10 个启用；容器 `allin-rsshub`，绑定 127.0.0.1:1200）、browserless（`allin-browserless`，127.0.0.1:3001，供 RSSHub puppeteer 路由与 L3 抓取）、Crawl4AI、trafilatura | 全文抓取 `enrich_content`：L1 HTTP + trafilatura → L2 Crawl4AI → L3 Browserless + trafilatura → 回退原始内容 |
| 媒体 | yt-dlp、ffmpeg | 视频 / 音频下载、转写前处理 |
| LLM | 可配置（`get_llm_config()`）；`.env` 与 `system_settings` 均无 LLM key | `analysis_result` 全表为空；日报 / 周报 periodic 任务已注释停用 |
| 外部元数据 | TMDb（影视，唯一元数据源）、Google Books（图书）、Emby（库存与观看事实，只读） | 只在用户主动触发的写入动作上出网 |
| 金融 | 蚂蚁 financial-data API 主源，akshare / 雪球降级 | MCP 四个金融工具；`FINANCIAL_DATA_ENABLED` 一键回退 |
| 部署 | Docker Compose（`docker-compose.home-server.yml`，机器本地文件），镜像 `allin-one:home-server` 四容器共用；容器只挂载 `.env`、`data/`、docker.sock、compose 文件，不挂载源码 | `deploy-home-server.sh`：rsync → build → 用新镜像跑迁移 → up → 健康检查 |
| 备份 | restic 0.18，仓库 `/mnt/sda2/backup/restic-allin-one` | `scripts/backup-home-server.sh`，手动运行；systemd timer 已装、停用 |
| 桌面端 | Fountain（Tauri，`fountain/`） | 读本地 Apple Books / 微信 API 等推送到后端；保留 |
| 文档校验 | `scripts/verify/drift/check.sh` | 模型 vs 真实库 vs `system_design.md` 表结构段三方对账 |

## 3. 系统分层

```
数据源层   source_configs × source_types 注册表
             采集型 Collector ─┐
             同步型 Syncer    ─┼─▶ content_items（kind）+ media_items
             推送型 Push      ─┤        │
             手工 / 站点录入   ─┘        ├─ 领域附表：watch_records / watch_logs / reading_progress / book_annotations
                                        └─ 金融另走 finance_data_points
处理层     流水线（模板步骤）：extract_content → enrich_content → translate → localize_media → transcribe → analyze → publish
           保留策略 content_retention.py；调度器 + 退避 + 周期性分析（system_settings）
视图层     页面：首页 /feed · 收藏 · 阅读 · 数据 · 仪表盘 · 数据源 · 信息站 · 图书馆 · 影视库 · 流水线 · 媒体管理 · 同步管理 · 系统设置
           接口：REST /api（X-API-Key）· MCP :8001（20 工具）
判断层     the-one（独立仓库，本仓库嵌套其下）：intel-query 拉取、MCP 调用；投递研判摘要与 brief 的接口尚未实现
```

**运行拓扑**（compose 服务）：`allin-one`（API + 前端，:8000）、`allin-worker-pipeline`、`allin-worker-scheduled`、`allin-mcp`（:8001）、`postgres`、`rsshub`（127.0.0.1:1200）、`browserless`（127.0.0.1:3001）；网络 `allin-network`；数据卷 `data`。共享镜像重建约 5–10 分钟。

**与 the-one 的边界**（现状）：

| 项 | 现状 |
|---|---|
| 物理位置 | 本仓库在 `the-one/allin-one/`，git 独立；the-one 的 `.gitignore` 排除它 |
| 数据方向 | 单向：the-one 通过 REST（`intel-query`）与 MCP 读内容、写标记（已读、收藏、影视标记、数据源管理）。本系统没有接收 brief 或研判摘要的接口（`routes/` 无 judgment / memo 端点） |
| 共享存储 | 无。the-one 不读写本系统数据库与 `data/` |
| 对象引用 | the-one 侧约定写 `content:<id>`；本系统主键 32 位十六进制 |
| 凭证 | `API_KEY` 在 `/opt/allin-one/.env`；the-one 侧存 `settings.local.json` 的 `ALLIN_API_KEY` |
| 上下文加载 | 在 the-one 会话里触碰本仓库文件时，本仓库 `CLAUDE.md`、`backend/CLAUDE.md` 自动叠加；本仓库 `.claude/settings.json` 的 Stop hook 在 the-one 会话不生效 |
