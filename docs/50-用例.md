# 50 用例

> 回答：人和 agent 现在怎么用这个系统、怎么确认它在正常工作。
> 核实日期：2026-09-24

## 1. 使用方式

### 1.1 站点（手机 / 桌面浏览器）

| 入口 | 做什么 |
|---|---|
| 首页 `/feed` | 刷信息流：按数据源 / 过滤器 / 未读筛选，打开详情，收藏，批量已读；播客内嵌播放 |
| 收藏 `/favorites` | 收藏列表：搜索；排序 最近收藏 / 最新发布 / 最新采集；媒体收藏独立 tab |
| 阅读 `/reading` | 跨书标注流：按书籍 / 类型（划线、笔记）/ 颜色过滤，搜索标注与笔记；目前无数据 |
| 数据 `/finance` | 行情与宏观时序图表，显示已触发告警。指标预设与告警阈值在数据源页新建 / 编辑 `api.akshare` 源的表单里配置，不在本页 |
| 仪表盘 `/dashboard` | 已处理 / 已打开 / 已收藏 / 互动（对话 + 笔记 + 批注合并一卡，为 0 时不显示）计数（含今昨对比）、84 天阅读热力图、7 天行为趋势、数据源偏好 Top 5、数据源健康 |
| 信息站 `/content` | 全部内容管理：搜索、状态、删除 |
| 图书馆 `/ebook` | 书架：搜索、按来源 / 作者 / 分类筛选、排序；详情页看标注、编辑元数据、Google Books 补全 |
| 影视库 `/films` | 海报网格；筛选状态 / 类型 / 年代 / 是否在 Emby / 评分；标记状态与评分、记观看日期与感想；手工添加（TMDb 搜索）；同步 Emby |
| 数据源 `/sources` | 增删改数据源、启停调度、绑定流水线、看采集记录 |
| 流水线 `/pipelines` | 模板与提示词管理 |
| 媒体管理 `/media` | 视频 / 音频 / 图片三 tab，下载 URL（yt-dlp）、播放、收藏、重试 |
| 同步管理 `/sync` | 各同步源的书籍 / 标注 / 视频计数、上次同步时间、手动触发、凭证 |
| 系统设置 `/settings` | 八个 tab：LLM 配置、内容过滤器、邮件推送、通知渠道、内容保留、智能调度（含失败退避）、平台凭证、影视资料库（TMDb key） |

### 1.2 外部脚本（Mac）

- `scripts/apple-books-sync.py`：读本地 BKLibrary SQLite，推送书籍与标注；launchd 定时。
- `scripts/wechat-read-sync.py --cookie`：读微信读书 Web API，推送书籍、进度、划线。
- `scripts/bilibili-sync.py --cookie --type favorites|history|dynamic`：B 站收藏夹 / 观看历史 / 关注动态，推送到 `/api/video/sync`。
- Fountain 桌面端（`fountain/`，Tauri）：同步模块 apple_books / wechat_read / bilibili / browser_bookmarks / kindle，走 `/api/{ebook,video,bookmark}/sync` 三步 API（setup / status / sync）。

### 1.3 the-one（agent）

**REST**：`the-one/scripts/intel-query.py`，base `http://192.168.1.103:8000`（脚本自行拼 `/api/...`；`ALLIN_API_BASE` 覆盖时不带 `/api`），头 `X-API-Key`。

```bash
python3 scripts/intel-query.py query --since-watermark --out /tmp/q.json   # 「情报」过滤器圈定的源，增量
python3 scripts/intel-query.py query --keyword 关键词 --days 7             # 不推进水位线
python3 scripts/intel-query.py mark-read --file /tmp/q.json --idx 1 2
python3 scripts/intel-query.py favorite  --file /tmp/q.json --idx 3
python3 scripts/intel-query.py advance-watermark --file /tmp/q.json        # 只有 digest 推进
```

**MCP**（192.168.1.103:8001，20 个工具）：

| 组 | 工具 |
|---|---|
| 内容 | `list_content`（信息流口径，排除 film）、`get_content_detail`、`toggle_favorite`、`mark_read`、`get_favorites_summary` |
| 数据源 | `get_sources`、`create_source`、`update_source`、`delete_source`、`toggle_source` |
| 运维 | `get_system_health`、`get_source_health`、`get_recent_failures`（与仪表盘同口径） |
| 影视 | `list_films`（分页，未标记的 status 为字符串 `unmarked`）、`search_film`（TMDb 预查）、`mark_films`（批量状态 / 评分 / 观看记录，`rewatch: true` 重看） |
| 金融 | `get_market_snapshot`、`get_stock_quote`、`get_kline`、`get_macro_indicator` |

影视 REST（无 MCP 时）：`GET /films?page=&page_size=500`、`GET /films/search?q=&year=`、`POST /films {tmdb_id(字符串), kind}`、`DELETE /films/{id}`（不碰 Emby）、`POST /films/records/batch`。

引用约定：the-one 的文档引用本系统对象写 `content:<id>`，不复制正文。

## 2. 验证方式

### 2.1 运行健康

| 检查 | 方式 |
|---|---|
| 容器与接口 | `./deploy-home-server.sh status`；`curl -H "X-API-Key: …" http://192.168.1.103:8000/api/sources` 应 200，无 key 应 401 |
| 采集与源健康 | MCP `get_system_health(time_range)` / `get_source_health` / `get_recent_failures`；仪表盘"信息源健康"三级堆叠条与 7 天失败率 |
| 同步 | 同步管理页的上次同步时间；`sync_task_progress` 最近记录；Emby 自动同步注册间隔 30 分钟、检查器每 10 分钟跑，`options_json._trigger=auto` 记录实际约每 40 分钟一条 |
| 任务队列 | `procrastinate_jobs` 无长期 `doing`；`cleanup_job_queue` 每日回收 |
| 文档漂移 | `scripts/verify/drift/check.sh`（模型 vs 库 vs `system_design.md`）；Stop hook `check-doc-drift.sh` |
| 金融数据 | `scripts/verify/financial_data/probe_api.py`（探针）、`verify_parity.py`（新旧源对拍，宏观偏差 <1%） |

### 2.2 数据完整性

| 检查 | 方式 |
|---|---|
| 备份可恢复 | `backup-home-server.sh check`；`restore-db latest <dir>` 取出 dump 灌进临时 postgres:17 容器，核对 `content_items`、`watch_records`、`alembic_version`（2026-09-23 演练时数值：11,484 / 1,177 / 0028，与当时生产一致） |
| 影视库 | `list_films` 总数与 Emby 库存对照（人工）；`GET /api/films/stats` 的 skeleton / partial / enrich_failed 计数（由 `enrichment_state()` 实时计算，非存储字段；单条详情字段名 `metadata_state`，取值 full / partial / skeleton / failed） |
| 图书馆 | `GET /api/ebook/sync/status` 的 `total_books` / `total_annotations`（当前 0 / 0） |
| 收藏落地 | 收藏条目应有 `processed_content` 且正文 `img` 指向 `/api/media/`（2026-09-24：24 条中 13 条满足，11 条无正文） |
| 采集增量 | `collection_records` 近 24 小时成功数；the-one 侧 `intel/digest-watermark.json` 年龄（`/health-check` 已接入：>7 天提示） |
