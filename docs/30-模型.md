## 1. 数据模型

**表清单**（22 张）：

| 组 | 表 | 说明 |
|---|---|---|
| 主表 | `source_configs` | 数据源：`source_type`、`is_active`、调度字段、`pipeline_template_id`、`credential_id`、`last_collected_at` |
| | `content_items` | 内容条目，见下 |
| | `media_items` | 内容的媒体文件，1:N，见下 |
| 影视附表 | `watch_records` | 片级状态：`status`（unmarked / backlog / want / watching / watched / dropped）、评分；每片一行 |
| | `watch_logs` | 每次观看：日期（年 / 月 / 日精度）、评分、感想；每片多行 |
| 图书附表 | `reading_progress` | 阅读进度、`is_finished`；每书一行 |
| | `book_annotations` | 标注：`external_id`、type（highlight / note）、颜色、原文、笔记、章节位置 |
| | `book_bookmarks` | 阅读器书签。阅读器已拆除，表为残留，0 行 |
| 金融 | `finance_data_points` | 列式时序：category、date_key、published_at、value / OHLC / NAV |
| 流水线 | `pipeline_templates`（8 个内置模板）、`pipeline_steps`、`pipeline_executions`、`prompt_templates` | 模板定义步骤；执行记录挂在内容上 |
| 运行记录 | `collection_records`（采集运行，调度算法输入；21,759 条自 8-30）、`sync_task_progress`（内置同步与外部推送，`_trigger` = manual / auto / push） | 两张表并存不合并 |
| 配置 | `platform_credentials`（3 条，Fernet 加密）、`system_settings`（调度、退避、清理、热点、周期性分析、内容过滤器、TMDb key） | |
| 框架 | `procrastinate_*` 4 张、`alembic_version`（head `0028_film_countries_iso`） | |

**`content_items` 字段**：

| 字段 | 含义 |
|---|---|
| `id` | 32 位十六进制主键 |
| `source_id` | 所属数据源，源删除时置空 |
| `kind` | 领域身份：article / audio / video / book / film / bookmark / note / file |
| `title` `url` `author` `published_at` `collected_at` | 元数据 |
| `external_id` | 源内去重键；`title_hash`（SimHash）+ `duplicate_of_id` 做跨源标题去重 |
| `raw_data` | JSONB，采集原文与领域字段（feed 原文 HTML、影片的 TMDb 详情与海报来源、书的 subjects 等）。全表 38MB |
| `processed_content` | 全文抓取 / 清洗后的正文，30 条非空 |
| `analysis_result` | LLM 输出 JSONB，当前全空 |
| `status` | pending / processing / ready / analyzed / failed |
| `is_favorited` `favorited_at` | 收藏（26 条） |
| `user_note` `chat_history` | 笔记、对话，均无数据 |
| `view_count` `last_viewed_at` `opened_at` | 已读与已打开 |

**`media_items` 字段**：`content_id`、`media_type`（image / video / audio / ebook）、`original_url`、`local_path`、`filename`、`status`（pending / downloaded / failed）、`metadata_json`、`playback_position`、`last_played_at`、`is_favorited`。348 行：播客音频 171、文章视频 82、文章图片 58、文章音频 37；其中 61 行有本地文件。

**领域字段的存放**：影视与图书的领域属性不拆列，放 `raw_data`；用户侧标记放各自附表。影片身份键为 TMDb id（`raw_data.tmdb_id`），Emby 项以 `emby:<id>` 为 `external_id`。

**枚举与词表**：`ContentKind`、`MediaType`、`ContentStatus`、`SourceType`、`Runner` 在 `backend/app/models/`；业务含义见 `business_glossary.md`。

## 2. 存储模型

| 数据 | 位置 | 备注 |
|---|---|---|
| 全部结构化数据与正文 | Postgres，docker volume `allin-one_postgres_data` | 101MB；`content_items` 49MB |
| 影视海报 | `/opt/allin-one/data/posters/<content_id>-<来源哈希>.jpg` | 1,197 张，64MB。入库时拉取落盘；接口未命中时从 Emby / TMDb 再拉一次写回；URL 带来源哈希，30 天 immutable |
| 本地化媒体（收藏文章的图片、下载的音视频） | `/opt/allin-one/data/media/<content_id>/` | 61 个文件 7.4MB；正文里的 `img` 改写为 `/api/media/` 路径 |
| 上传文件 | `/opt/allin-one/data/uploads/<content_id>/` | 现无 |
| 日志 | `/opt/allin-one/data/logs/` | 520KB |
| 机器本地配置 | `/opt/allin-one/.env`（API key、加密密钥、Cookie、外部 API key）、`docker-compose.home-server.yml`、`.restic-password` | 不在仓库，rsync 不覆盖 |
| 凭证 | `platform_credentials`，Fernet 加密，密钥在 `.env` | Emby key、B 站 Cookie 等 |

**备份**：`scripts/backup-home-server.sh` 把 `pg_dump -Fc` + `data/`（排除 logs）+ `.env` + compose 打进同一个 restic 快照，仓库 `/mnt/sda2/backup/restic-allin-one`（1TB 数据盘），保留 30 天 / 8 周 / 12 月。现有快照 1 份（2026-09-23 19:17，85.6MiB，已恢复验证）。systemd timer 已安装但停用，备份手动运行。

**生产目录与仓库**：`/opt/allin-one` 是仓库的 rsync 镜像（排除 `.git`、`.env`、`data`、`certs`、`restore`、`.cache`、`.claude`、`.mcp.json`），不是 git checkout；代码打进镜像，容器不挂载源码。
