## 1. 数据模型

**表清单**（22 张）：

| 组 | 表 | 说明 |
|---|---|---|

| | `content_items` | 内容条目，见下 |
| | `media_items` | 内容的媒体文件，1:N，见下 |

| | `watch_logs` | 每次观看：日期（精度 day / month / year / release，release = 按上映日）、评分、感想；每片多行 |
| 图书附表 | `reading_progress` | 阅读进度：`cfi`、`progress` 百分比、章节序号 / 标题；每书一行（唯一索引） |

| 框架 | `procrastinate_*` 4 张、`alembic_version`（head `0028_film_countries_iso`） | |

**`content_items` 字段**：

| 字段 | 含义 |
|---|---|
| `id` | 32 位十六进制主键 |
| `source_id` | 所属数据源，源删除时置空 |
| `kind` | 领域身份：article / audio / video / book / film / bookmark / note / file |
| `title` `url` `author` `published_at` `collected_at` | 元数据 |
| `external_id` | 源内去重键；`title_hash`（SimHash）+ `duplicate_of_id` 做跨源标题去重 |
| `raw_data` | JSONB，采集原文与领域字段（feed 原文 HTML、影片的 TMDb 详情、`provider_ids`、海报来源与 Emby 块）。全表 39MB（文本长度；TOAST 压缩后 27MB） |
| `processed_content` | 全文抓取 / 清洗后的正文，30 条非空 |
| `analysis_result` | LLM 输出 JSONB，当前全空 |
| `status` | pending / processing / ready / analyzed / failed |
| `is_favorited` `favorited_at` | 收藏（24 条，2026-09-24） |
| `user_note` `chat_history` | 笔记、对话，均无数据 |
| `view_count` `last_viewed_at` `opened_at` | 已读与已打开 |

**`media_items` 字段**：`content_id`、`media_type`（image / video / audio / ebook）、`original_url`、`local_path`、`filename`、`status`（pending / downloaded / failed）、`metadata_json`、`playback_position`、`last_played_at`、`is_favorited`。351 行（2026-09-24）：播客音频 173、文章视频 82、文章图片 58、文章音频 38；其中 61 行有本地文件（`status=downloaded`），其余 290 行 `pending`，只记远程 URL。

**领域字段的存放**：影视与图书的领域属性不拆列，放 `raw_data`；用户侧标记放各自附表。影片身份键是 `external_id` = `tmdb:<movie|tv>:<id>`（`tmdb_external_id()`），TMDb id 同时存 `raw_data.provider_ids.tmdb`；Emby 条目只在缺 TMDb id 时以 `emby:<item_id>` 为 `external_id`，补到 TMDb id 后改写为 `tmdb:*`。现库 1,177 片全为 `tmdb:*`，Emby item id 存 `raw_data.emby` 与 `raw_data.poster.emby_item_id`。

**枚举与词表**：`ContentKind`、`MediaType`、`ContentStatus`、`SourceType`、`Runner` 在 `backend/app/models/`；业务含义见 `business_glossary.md`。

## 2. 存储模型

| 数据 | 位置 | 备注 |
|---|---|---|
| 全部结构化数据与正文 | Postgres，docker volume `allin-one_postgres_data` | 库 103MB（`pg_database_size`），volume 实占 174MB；`content_items` 50MB |
| 影视海报 | `/opt/allin-one/data/posters/<content_id>-<来源哈希>.jpg` | 1,197 张，64MB。入库时拉取落盘；接口未命中时从 Emby / TMDb 再拉一次写回；URL 带来源哈希，30 天 immutable |
| 本地化媒体（收藏文章的图片、下载的音视频） | `/opt/allin-one/data/media/<content_id>/` | 61 个文件 7.4MB；正文里的 `img` 改写为 `/api/media/` 路径 |
| 上传文件 | `/opt/allin-one/data/uploads/<content_id>/` | 现无 |
| 日志 | `/opt/allin-one/data/logs/` | 520KB |
| 机器本地配置 | `/opt/allin-one/.env`（API key、加密密钥、Cookie、外部 API key）、`docker-compose.home-server.yml`、`.restic-password`、`.backup.env` | 不在仓库；四者均在 `deploy-home-server.sh` 的 rsync 排除列表（后两项 2026-09-24 补入，此前 `--delete` 会删掉它们） |
| 凭证 | `platform_credentials`，Fernet 加密（`core/crypto.py`），密钥 `CREDENTIAL_ENCRYPTION_KEY` 在 `.env` | 3 条：Emby key、B 站 Cookie 等 |

**备份**：`scripts/backup-home-server.sh` 把 `pg_dump -Fc` + `data/`（排除 logs）+ `.env` + compose 打进同一个 restic 快照，仓库 `/mnt/sda2/backup/restic-allin-one`（1TB 数据盘），保留 30 天 / 8 周 / 12 月。现有快照 1 份（2026-09-23 19:17，85.6MiB）；2026-09-23 在一次性 postgres:17 容器里 `pg_restore` 核对过行数（未留产物，见 60-运维 §5）。systemd timer 已安装但停用，备份手动运行。

**生产目录与仓库**：`/opt/allin-one` 是仓库的 rsync 镜像（排除 `.git`、`.env`、`.restic-password`、`.backup.env`、`data`、`certs`、`restore`、`.cache`、`.claude`、`.mcp.json`、`node_modules`、`dist`、`__pycache__`、`.DS_Store`、`fountain`、`docker-compose.home-server.yml*`），不是 git checkout；代码打进镜像，容器不挂载源码。
